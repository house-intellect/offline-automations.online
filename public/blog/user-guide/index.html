Руководство по интеграции конвейера «ДокСинтез»

Данное руководство предназначено для специалистов и системных администраторов предприятий, приобретших решение «ДокСинтез» и осуществляющих его внедрение в рабочий контур компании.

Краткий регламент этапов интеграции:

  1. Подготовка эталонов (PO & Бюджетные статьи):

    • Выгрузите актуальные реестры действующих договоров/заказов-соглашений (Purchase Orders) и классификатор статей затрат в формате JSON / Excel / CSV.
    • Разместите файлы в каталоге эталонных данных data/reference/.

  2. Настройка локального сервиса нейросетей:

    • Убедитесь в активности локального сервера Ollama (http://127.0.0.1:11434).
    • Зарегистрируйте квантованные GGUF-модели GLM-OCR (оптическое распознавание и табличный парсинг) и BigBang-v1 (семантическое сопоставление номенклатуры).

  3. Автоматизация конвейера (Cron / Task Scheduler):

    • Настройте ночной запуск скрипта обработки входящей папки с PDF-документами (input_pdf/).
    • Каждое утро ответственные лица получают готовый верифицированный реестр в папке output_reports/ с флагами математического соответствия и детализацией аномалий.

Техническая поддержка: Если у вашей команды возникли вопросы в процессе интеграции или требуется помощь в адаптации коннекторов к ERP/1C, свяжитесь с инженерной службой: sirglepp@gmail.com.
