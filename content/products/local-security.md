Финансовые документы, условия контрактов, реестры заказов (PO) и закупочные цены составляют основу коммерческой тайны любого предприятия. Использование публичных облачных нейросетевых API (OpenAI, Anthropic и др.) создает неприемлемые риски утечки данных, регуляторных штрафов и зависимости от зарубежной инфраструктуры.

![Аппаратный фундамент ДокСинтеза](/img/products/local-security.webp)

**«ДокСинтез» спроектирован по принципу Zero-External-Dependency (Нулевая зависимость от внешних сетей).**

---

### Архитектура безопасности

* **Автономное выполнение:** Все вычисления — оптическое распознавание документов, семантический анализ локальной LLM и математический аудит — происходят на серверах внутри защищенного корпоративного периметра заказчика.
* **Физическая изоляция:** Сервер обработки может функционировать в изолированном сегменте корпоративной сети (Air-Gapped) без доступа в Интернет.
* **Соответствие требованиям безопасности:** Полное соответствие требованиям Федерального закона № 152-ФЗ «О персональных данных» и внутренним регламентам информационной безопасности крупных корпораций.

---

### Аппаратные требования для локального развертывания

Система оптимизирована для работы с современными квантованными моделями высокой точности (30B+ параметров) и минимальными накладными расходами:

| Параметр | Минимальные требования | Рекомендуемая конфигурация |
| :--- | :--- | :--- |
| **Процессор (CPU)** | Поддержка AVX2 (обязательно) | Современный многоядерный CPU (Intel Core i7/i9 / AMD Ryzen 9 / Xeon / EPYC) |
| **Оперативная память (RAM)** | 32 ГБ RAM (критический минимум) | 64 ГБ RAM и выше |
| **Накопитель** | SSD (от 500 ГБ) | Высокоскоростной NVMe SSD |
| **Графический ускоритель (GPU)** | — | NVIDIA RTX 3060 / 4060 / 4080+ (от 8–16 ГБ VRAM) |
| **Экосистема Apple** | — | Apple Silicon Mac (M-серия) с 32+ ГБ объединенной памяти |

> **Примечание архитектора:** Объем оперативной памяти от 32 ГБ является ключевым условием для комфортного удержания в памяти локальной нейросетевой модели и поддержания широкого контекстного окна при анализе многостраничных пакетов PDF.
