# ДокСинтез — Локальная гибридная система автоматизации финансового контроля

Сайт проекта: [https://offline-automations.online/](https://offline-automations.online/)

Интеллектуальный конвейер обработки входящих первичных документов (УПД, акты, накладные, счета-фактуры) на базе локальных LLM и детерминированного математического аудита в изолированном контуре предприятия.
